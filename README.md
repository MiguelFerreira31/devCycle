# 🚀 DevCycle – Agência de Desenvolvimento Web

**DevCycle** é um site front-end responsivo criado para divulgar os serviços de uma agência de desenvolvimento web. Utilizando tecnologias modernas como **HTML5**, **SCSS**, **JavaScript**, **GSAP** e **Bootstrap 5**, o projeto entrega uma experiência visual impactante com animações fluidas e layout adaptável a todos os dispositivos.

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura semântica e acessível.
- **SCSS (Sass)** – Estilo modular e fácil de manter.
- **JavaScript (ES6+)** – Interações e lógica de navegação.
- **GSAP** – Animações fluidas e performáticas.
- **Bootstrap 5** – Sistema de grid e componentes responsivos.

## 🎯 Objetivo

Divulgar os serviços da **DevCycle**, uma agência especializada em soluções web modernas, com foco em design, performance e experiência do usuário.


## 🧩 Funcionalidades

- Apresentação da agência e serviços
- Animações com scroll e entrada de elementos
- Design responsivo com Bootstrap
- Estrutura otimizada para SEO on-page
- Código limpo e reutilizável
